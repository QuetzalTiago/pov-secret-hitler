# Spike: CC0 glTF models (todo #169, milestone 723)

Goal: replace the procedural characters and props with CC0 glTF models. This step only fetches, inspects and optimises the assets and documents them. No game code was touched.

Raw downloads live outside git in `C:\Users\Tiago\code\pov-assets-src\` (`chars/`, `props/`, `tex/`, `env/`). Reproduction commands are in `scripts/models.md`. Credits are in `client/models/CREDITS.md`.

Every license was checked on the source page: poly.pizza shows "CC0 1.0" in each model's metadata, Poly Haven publishes everything as CC0 (https://polyhaven.com/license).

## Characters

Pack actually used: Quaternius character models as mirrored on poly.pizza (CC0). The brief's first choice, the "Ultimate Animated Character Pack" (https://quaternius.com/packs/ultimatedanimatedcharacter.html), could not be fetched directly (see "Needs a human download"), but poly.pizza hosts several of its characters, and a second, smaller Quaternius family with a shared 31-bone skeleton and a seated clip. That second family is what is committed.

All five committed characters share one skeleton (identical bone name set, verified in script), the same 11 clips, and plain colour materials (no image textures). Note on the male clip prefix: male files use `Man_*` clip names, female files use `Female_*`. The armature is `HumanArmature`.

### Size and axes

Measured with three.js r186 `Box3.setFromObject(scene, true)` (precise, skinned bind pose), in the file's own units:

| File | Height (Y) | Width (X) | Depth (Z) |
|---|---|---|---|
| man_suit | 4.83 | 1.42 | 0.92 |
| man_casual | 4.83 | 1.43 | 0.82 |
| woman_dress | 4.66 | 1.40 | 1.22 |
| woman_casual | 4.64 | 1.41 | 0.82 |
| woman_tank | 4.66 | 1.40 | 0.82 |

Important: the models are NOT in metres. The armature node carries a scale of 100 and the mesh is about 4.8 units tall. For a 1.8 m person use a uniform scale of about 0.373 (women about 0.39 for 1.8 m, or 0.37 for 1.72 m). Decide per character in code.

Up axis: +Y. Forward axis: not verified visually. The body bounding box extends further towards +Z than -Z (feet and nose side), and glTF convention is +Z forward, so assume characters face +Z. Please confirm when the first one is placed in the scene. The root nodes are `RootNode > HumanArmature` (rotation -90 deg about X, scale 100) and a sibling `SkinnedMesh` node with the same transform.

Quantisation check: `gltf-transform quantize` rewrites positions as normalised int16 and compensates in the inverse bind matrices. I verified with a small script (rest pose skinning) and with three's `GLTFLoader` that the skinned bounding box of the quantised file is identical to the raw file to three decimals, and that all 11 clips and the 31-joint skin survive (`clips 11` in the loader).

Notes:
- Poly Haven has no whisky bottle, drinking glass or ashtray (its only bottle model with alcohol, `wine_bottles_01`, is 28,848 tris). The bottles and glasses therefore come from poly.pizza, filtered to CC0 only.
- No ashtray: every ashtray on poly.pizza is CC-BY (Poly by Google, J-Toastie, Jarlan Perez) and Poly Haven has none. Not committed. If wanted, model one procedurally (a short cylinder).

- The chair and stool are "painted wooden" (a country look) rather than bentwood; they are the lightest Poly Haven seating that reads as period furniture.

## Ultimate Animated Character Pack suits (evaluated 2026-10-12, #176): rejected

The Drive glTF folder (https://drive.google.com/drive/folders/1UNNT0MeVX0O04RGgu8aLkKe3fwB9_t-A) lists file ids through `https://drive.google.com/embeddedfolderview?id=<folder>`, and `https://drive.usercontent.google.com/download?id=<id>&export=download&confirm=t` downloaded them once the quota had reset. Raw files: `pov-assets-src/chars/ultimate/` (`Suit_Male`, `Suit_Female`, `OldClassy_Male`, `OldClassy_Female`, as .gltf plus .glb copies).

- Style: the Drive pack is Quaternius's chibi line: big heads, anime eyes, mitten fists. Next to the realistic `man_suit` patron it looks like a different game. OldClassy is a top hat, suspenders and cream trousers rather than a suit, and the hats were removed on purpose (#192).
- Rig: 23 bones (`Body, Hips, Abdomen, Torso, Neck, Head, Shoulder/UpperArm/LowerArm/Fist.L/R, UpperLeg/LowerLeg/Foot.L/R, PoleTarget.L/R`), not the 62-bone poly.pizza family. It has no finger bones (rigged.ts uses `FingersR`, `Thumb1R`, `Palm`, `MiddleHand`) and no `Sitting` clip, only `SitDown`/`StandUp`.
- Budget: 5,432 to 7,008 tris; only OldClassy_Male is under the 6000 cap. About 1.2 MB each as GLB with 17 clips.
- Verdict: keep the current 31-bone family. If a better suit is still wanted, Business Man (above) remains the better candidate.
