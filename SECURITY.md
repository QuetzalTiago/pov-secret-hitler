# Security policy

The game is hosted on the public internet, so security reports are very welcome.

**Please don't open a public issue for a vulnerability.** Report it privately through
[GitHub's private vulnerability reporting](https://github.com/QuetzalTiago/pov-secret-hitler/security/advisories/new).

Especially interesting:
- a client receiving information its player should not have (other players' roles, cards, votes before the reveal);
- a client making moves it isn't allowed to make, or acting for another seat;
- crashing or stalling the server or a room, bypassing the rate, size or connection limits;
- leaking server secrets (API keys, tokens).

Please include steps to reproduce. You'll get a response as soon as possible, and credit in the fix if you'd like.
